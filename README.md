# .github

This is the organization-level `.github` repository for **[The WP Squad](https://thewpsquad.com)**. GitHub treats it as the home for org-wide defaults, so it holds two things:

1. **Our org profile** — [`profile/README.md`](profile/README.md), rendered at the top of the [github.com/thewpsquad](https://github.com/thewpsquad) organization page.
2. **Community-health defaults** — [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SUPPORT.md`](SUPPORT.md), and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). GitHub applies each of these to **every** repository in the organization that doesn't ship its own copy.

You almost never need to clone this repo directly — edit a file here and the change propagates across the org.

## Who we are

The WP Squad builds modules and tools that extend the Divi, Extra, and Divi Builder page-building experience. Our flagship is **[Squad Modules](https://squadmodules.com)** — an all-in-one Divi plugin with a Lite build (free, on WordPress.org) and a Pro build.
