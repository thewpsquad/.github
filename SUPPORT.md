# Support

Need a hand? Here's where to get help with The WP Squad products.

## Before you ask

- 📚 **Read the docs** — most questions are answered in our [documentation](https://squadmodules.com/docs/): installation, module guides, and troubleshooting.
- 🆕 **Check the changelog** — the behavior you're seeing may already be fixed in a newer release: [squadmodules.com/changelog](https://squadmodules.com/changelog/).
- ✅ **Update first** — make sure you're on the latest version of the plugin, Divi, WordPress, and PHP.

## Where to get help

| I want to… | Go to |
|---|---|
| Ask a product or setup question | [squadmodules.com/support](https://squadmodules.com/support/) |
| Get help with a **free** plugin | The plugin's [WordPress.org support forum](https://wordpress.org/support/plugin/squad-modules-for-divi/) |
| Get **Pro** / priority support | [squadmodules.com/support](https://squadmodules.com/support/) (with your license) |
| Report a bug in open-source code | [squad-modules-lite issues](https://github.com/thewpsquad/squad-modules-lite/issues) |
| Report a **security** issue | See [SECURITY.md](SECURITY.md) — please don't post it publicly |

## Community

- 👥 [Facebook community group](https://www.facebook.com/groups/squadmodules/)

We read everything that comes in and do our best to reply promptly. Please include your environment (WordPress, PHP, and Divi versions), the plugin version, and clear steps to reproduce — it helps us help you faster.
